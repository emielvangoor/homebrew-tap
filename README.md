# emielvangoor/homebrew-tap

Homebrew formulae for [paseo-tui](https://github.com/emielvangoor/paseo-tui), the keyboard-first terminal
client for [Paseo](https://github.com/getpaseo/paseo). Works on macOS and Linux (arm64 and x86_64).

```sh
brew install emielvangoor/tap/paseo-tui
brew upgrade paseo-tui
```

The formula is updated automatically by paseo-tui's release workflow, so please don't edit it by hand.
Report problems in the [paseo-tui issues](https://github.com/emielvangoor/paseo-tui/issues).
